# Jupyter notebooks

This folder contains notebook-based workflows used for spatial trajectory and RNA velocity analyses.

## Notebooks

### `stLearn_spatial_trajectory_CCI.ipynb`

Structured workflow for Xenium ROI analysis, stLearn spatial pseudotime, branch marker discovery, and ligand–receptor hotspot analysis.

### `SIRV_scVelo_PAGA_spatial_velocity.ipynb`

Structured workflow for scRNA-seq RNA velocity using velocyto/scVelo, PAGA graph abstraction, SIRV-style projection onto Xenium spatial cells, and spatial visualization of inferred transition relationships.
